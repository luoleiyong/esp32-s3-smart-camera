# ESP32-S3 智能相机

[English](README.md) | **简体中文**

基于 ESP32-S3（N16R8）的完整智能相机：OV2640 摄像头、1.44 寸 ST7735S TFT 取景器、
摇杆菜单、microSD 存储、WiFi 网页控制台、机内 AVI 录像、照片上传与 OTA 升级。

```
┌──────────────────────────────────────────────┐
│  TFT 128×128 取景器 + 中文界面                │
│  OV2640 拍照，最高 UXGA 1600×1200             │
│  1–4× 数字变焦 · 手动快门 · 手持防抖          │
│  microSD 照片 / 缩略图 / AVI 录像             │
│  网页：推流、拍照、图库、设置、状态、固件升级  │
└──────────────────────────────────────────────┘
```

## 快速开始

```bash
git clone https://github.com/luoleiyong/esp32-s3-smart-camera.git
```

1. 用 Arduino IDE 打开 `ESP32S/ESP32S.ino`。
2. 按[开发板设置](#开发板设置)配置（16 MB Flash、OPI PSRAM、支持 OTA 的分区方案）。
3. 安装[依赖库](#软件环境)。
4. 以 921600 波特率烧录，用 115200 打开串口监视器。
5. 首次开机会进入配网热点：连接 `ESP32-S3-CAM-Setup` / `12345678`，
   打开 `http://192.168.4.1` 填写 WiFi（详见[首次开机与配网](#首次开机与配网)）。

## 功能特性

### 影像

| 功能 | 说明 |
| --- | --- |
| 实时预览 | OV2640 输出到 TFT 的 128×96 预览区，约 15 fps（间隔 66 ms） |
| 拍照 | JPEG，最高 UXGA 1600×1200，保存到 microSD |
| 分辨率 | QVGA / VGA / SVGA / XGA / SXGA / UXGA（TFT 菜单不含 VGA） |
| 画质 | JPEG 质量 4–15（网页），预设 Q5/Q8/Q10/Q15/Q20（TFT） |
| 数字变焦 | 1× / 2× / 3× / 4×，预览与拍照同时生效 |
| 手动曝光 | 自动或手动；快门 `aec_value` 0–1200，增益 0–30 |
| 手持防抖 | 连拍 3 张，保留 JPEG 码流最大（细节最多）的一张 |
| 场景优化 | 标准 / 夜间增强 / 逆光补偿 |
| 自拍倒计时 | 关 / 2 s / 5 s / 10 s；倒计时期间预览持续刷新 |
| 时间水印 | 可选 `YYYY-MM-DD HH:MM:SS`（变焦时含倍率），白字黑描边 |
| 浏览器录像 | 网页端用 `MediaRecorder` 把实时画面录成 WebM |
| 机内录像 | MJPEG 帧封装成 AVI 写入 SD 卡，5/10/15 fps |

### 设备与连接

| 功能 | 说明 |
| --- | --- |
| TFT 界面 | 1.44 寸 ST7735S 128×128，白底中文菜单与状态栏 |
| 操作 | 五向摇杆 + IO0 按键手势 |
| LED 状态 | 板载 WS2812：待机呼吸、拍照闪白、AP 蓝闪、错误红闪 |
| WiFi | Station 模式 + 首次配网 AP 门户（仅 2.4 GHz） |
| mDNS | `http://esp32s3cam.local` |
| 时间 | NTP 自动对时，UTC+8 |
| 网页控制台 | 推流、远程拍照、图库、设置、运行状态 |
| 照片上传 | multipart HTTP POST，可自动上传；兼容 Telegram `sendPhoto` |
| OTA | ArduinoOTA + 浏览器 `/update` 上传固件 |
| 运行自愈 | 连续取帧失败自动重初始化相机；SD 写失败自动重挂载重试 |
| 双核 | Core 1 负责预览，Core 0 负责界面/网页/OTA |

### 可选高级开关（默认全部关闭）

| 开关 | 作用 |
| --- | --- |
| JPEG 预览 | 传感器直接输出 JPEG，由 TJpgDec 解码。大幅降低 PSRAM 带宽与发热，数字变焦仍可用 |
| 硬件窗口变焦 | 用 OV2640 `set_res_raw()` 裁剪，拍照与 MJPEG 推流都能全分辨率变焦且无需重编码。实验性；仅支持 4:3 预设 |

## 硬件清单

| 器件 | 规格 | 说明 |
| --- | --- | --- |
| 主控板 | ESP32-S3 **N16R8** | 必须 16 MB Flash + 8 MB **OPI** PSRAM |
| 摄像头 | OV2640 模块 | 8 位并口 + SCCB；引脚按 ESP32-S3-EYE 定义 |
| 显示屏 | ST7735S 1.44 寸 TFT | 128×128，SPI，3.3 V 逻辑 |
| 摇杆 | 双轴模拟 + 按下按键 | 如 KY-023 / PS2 摇杆 |
| 存储 | microSD 卡 + 卡座 | FAT32，SD_MMC 1 位模式 |
| 按键 | IO0（BOOT）按键 | 多数开发板板载；外接对地即可 |
| RGB 灯 | GPIO48 板载 WS2812 | 可选 |
| 电源 | 5 V / 1 A USB 供电 | 摄像头与 SD 有电流冲击，弱 USB 口会导致重启 |

> 固件按 **16 MB Flash + 8 MB OPI PSRAM** 配置。PSRAM 容量不足或选成 QSPI PSRAM
> 会导致相机初始化失败或内存不足。

### 完整引脚表

| 摄像头信号 | ESP32-S3 GPIO | 说明 |
| --- | --- | --- |
| XCLK | 15 | 20 MHz 主时钟 |
| SIOD / SDA | 4 | SCCB 数据 |
| SIOC / SCL | 5 | SCCB 时钟 |
| Y9 / D7 | 16 | |
| Y8 / D6 | 17 | |
| Y7 / D5 | 18 | |
| Y6 / D4 | 12 | |
| Y5 / D3 | 10 | |
| Y4 / D2 | 8 | |
| Y3 / D1 | 9 | |
| Y2 / D0 | 11 | |
| VSYNC | 6 | |
| HREF | 7 | |
| PCLK | 13 | |
| PWDN | — | 不接（`-1`） |
| RESET | — | 不接（`-1`） |
| VCC / GND | 3.3 V / GND | 靠近模块加去耦电容 |

> 不同 OV2640 转接板的数据脚丝印不一致，请按上表的 **Y2…Y9** 对应，
> 不要照抄其它板子的 `D0…D7` 顺序。

#### ST7735S TFT（SPI）

| TFT 信号 | ESP32-S3 GPIO | 说明 |
| --- | --- | --- |
| CS | 1 | 片选 |
| DC (A0) | 19 | 数据 / 命令 |
| RST | 20 | 复位 |
| SDA / MOSI | 21 | SPI 数据输入 |
| SCL / SCLK | 47 | SPI 时钟，20 MHz |
| BL / LED | 45 | 背光，高电平点亮 |
| VCC | 3.3 V | 不要用 5 V 逻辑 |
| GND | GND | |

> 本项目不使用 MISO（屏幕只写不读）。
> SPI 固定 **20 MHz**：实测 27 MHz 在该模块上会导致整屏白屏；除非排线很短且屏幕
> 确认支持，否则不要调高。

#### 摇杆

| 摇杆引脚 | ESP32-S3 GPIO | 说明 |
| --- | --- | --- |
| VRX | 14 | ADC 输入 |
| VRY | 3 | ADC 输入 |
| SW | 46 | 低电平有效，内部上拉 |
| +5V / VCC | 3.3 V | 用 3.3 V，不要接 5 V |
| GND | GND | |

> GPIO46 是启动 Strapping 引脚，上电/复位时不要按住摇杆。

#### microSD 卡（SD_MMC，1 位）

| SD 信号 | ESP32-S3 GPIO | 说明 |
| --- | --- | --- |
| CLK | 39 | |
| CMD | 38 | |
| D0 / DAT0 | 40 | 1 位模式；DAT1–DAT3 不接 |
| VCC | 3.3 V | |
| GND | GND | |

> 使用 FAT32 格式的卡。SD 排线尽量短；杜邦线过长会导致挂载失败或 40 MHz 写入错误。

#### 按键与 RGB 灯

| 信号 | ESP32-S3 GPIO | 说明 |
| --- | --- | --- |
| 按键 | 0（IO0） | 对地；内部上拉；BOOT Strapping 引脚 |
| WS2812 | 48 | 板载 RGB 灯，可选 |

### 连接总览

```
                    ┌─────────────────────────────────┐
                    │        ESP32-S3 (N16R8)         │
                    │                                 │
  OV2640  ──────────┤ 8 位并口 (Y2..Y9)               │
  (摄像头)          │ + XCLK / VSYNC / HREF / PCLK     │
                    │ + SCCB (SDA 4, SCL 5)            │
                    │                                 │
  ST7735S ──────────┤ SPI: CS 1, DC 19, RST 20,       │
  (TFT)             │      MOSI 21, SCLK 47, BL 45     │
                    │                                 │
  microSD ──────────┤ SD_MMC 1 位: CLK 39, CMD 38,    │
  (SD_MMC)          │              D0 40              │
                    │                                 │
  摇杆    ──────────┤ VRX 14 (ADC), VRY 3 (ADC),      │
                    │ SW 46 (GPIO)                    │
                    │                                 │
  按键    ──────────┤ IO0（接 GND）                   │
  WS2812  ──────────┤ GPIO48（板载）                  │
                    └─────────────────────────────────┘
```

### 接线注意事项

1. **必须共地**：主板、摄像头、TFT、摇杆、SD 卡座的地线要连在一起。
2. **只允许 3.3 V 逻辑**：所有外设均为 3.3 V，切勿把 5 V 接入 GPIO。
3. **总线尽量短**：摄像头并口与 20 MHz SPI 最怕干扰，飞线建议不超过 10 cm，
   数据线长度尽量一致。
4. **供电要稳**：使用 5 V / 1 A 电源。摄像头启动与 SD 写入有电流尖峰，
   弱 USB 口会引起掉电重启或串口打印 `Camera FAIL`。
5. **引脚占用**：固件使用 GPIO 0、1、3–21、38–40、45–48，不要再复用于其它外设。
6. **Strapping 引脚**：IO0（按键）与 IO46（摇杆按下）会影响启动模式，
   上电/复位时不要按住。

## 软件环境

### Arduino IDE

1. 安装 **Arduino IDE 2.x**。
2. 在 *首选项 → 其他开发板管理器地址* 添加：

   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```

3. 在开发板管理器安装 **esp32 by Espressif Systems**（实测 **3.3.8**，需 3.x）。
4. 在库管理器安装：

   | 库 | 实测版本 | 用途 |
   | --- | --- | --- |
   | Adafruit GFX Library | 1.12.6 | 图形绘制 |
   | Adafruit ST7735 and ST7789 Library | 1.11.0 | ST7735S 驱动 |
   | U8g2_for_Adafruit_GFX | 1.8.0 | TFT 中文渲染 |
   | TJpg_Decoder | 1.1.0 | JPEG 解码（预览、图库、变焦、水印） |

   以下库随 ESP32 核心自带，无需单独安装：
   `WiFi`、`WebServer`、`SD_MMC`、`SPI`、`Preferences`、`ArduinoOTA`、`Update`、
   `ESPmDNS`、`HTTPClient`、`NetworkClientSecure`。

### 开发板设置

用 Arduino IDE 打开 `ESP32S/ESP32S.ino`，选择开发板 **ESP32S3 Dev Module**，然后设置：

| 项目 | 值 |
| --- | --- |
| Board | ESP32S3 Dev Module |
| Flash Size | **16 MB (128 Mb)** |
| PSRAM | **OPI PSRAM** |
| Partition Scheme | **16M Flash (3MB APP / 9.9MB FATFS)** |
| CPU Frequency | **240 MHz** |
| Flash Mode | **QIO 80 MHz** |
| Upload Speed | 921600（烧录失败可降到 460800） |
| USB CDC On Boot | Disabled |
| Erase All Flash Before Sketch Upload | Disabled（仅清空 WiFi 设置时临时开启） |

> **OTA 需要两个 app 分区。** 不要选 *Huge APP (3MB No OTA/1MB SPIFFS)*：
> 该方案没有 OTA 分区，ArduinoOTA 与网页升级都会失败。推荐 `app3M_fat9M_16MB`。

项目自带 `ESP32S/build_opt.h`，内容为 `-O2`，用于覆盖核心默认的 `-Os` 以提升运行性能。

`USB CDC On Boot` 设为 **Disabled**，`Serial` 输出走 USB-UART 桥。若你的开发板只引出
原生 USB 口（没有 USB-UART 芯片），请改为 **Enabled** 才能看到串口日志。

## 首次开机与配网

### 正常启动（Station 模式）

开机后设备会用 NVS 中保存的 WiFi 账号尝试连接，超时约 10 秒。连接成功后：

- TFT 状态栏显示 **WiFi已连接** 与 NTP 时间；
- 串口打印设备 IP；
- 浏览器访问 `http://<设备IP>` 或 `http://esp32s3cam.local`；
- 不会启动 AP 配网热点。

ESP32 只支持 **2.4 GHz WiFi**，5 GHz 的 SSID 无法连接。

### 首次配网（AP 模式）

若没有保存的账号，或保存的网络连不上，设备会自动进入 AP 模式：

| 项目 | 值 |
| --- | --- |
| SSID | `ESP32-S3-CAM-Setup` |
| 密码 | `12345678` |
| 配网页面 | `http://192.168.4.1` |

步骤：

1. 手机或电脑连接 `ESP32-S3-CAM-Setup`。
2. 打开 `http://192.168.4.1`。
3. 从扫描列表选择路由器（或手动输入 SSID），填写密码。
4. 点击 **Connect**。连接成功后设备自动重启并保存账号。
5. 手机/电脑重新连回同一路由器，访问新 IP 或 `http://esp32s3cam.local`。

若连接失败，设备会退回 AP 模式，可再次尝试。
AP 模式只提供配网页面；连上路由器后才可使用相机控制台。

### 更换 WiFi / 重新配网

固件没有运行时的"重置 WiFi"按钮。要更换网络：

1. 在 Arduino IDE 中把 **Erase All Flash Before Sketch Upload** 设为 **Enabled**，
   烧录一次后改回 Disabled；**或** 用 `esptool.py erase_flash` 擦除后重新烧录。
2. 下次开机会进入 AP 模式，按上面的步骤配网。

擦除 Flash 会同时清除 NVS 中的相机设置（亮度、变焦等）。

### 时间同步

联网后通过 NTP（`pool.ntp.org`）对时，时区为 **UTC+8**。时间用于状态栏、照片文件名
与时间水印。无外网时时钟不会生效：水印会跳过而不是烧录错误时间，文件名回退为数字编号。

## 使用教程

### TFT 界面布局

```
┌──────────────────────────────┐
│ 智能相机            标题栏    │  16 px
├──────────────────────────────┤
│                              │
│        实时预览画面           │  128 × 96
│        （宽 128 px）          │
│                              │
├──────────────────────────────┤
│ WiFi已连接        12:34:56   │  16 px 状态栏
└──────────────────────────────┘
```

状态栏不显示 IP（128 px 放不下）；IP、信号强度与推流状态在菜单 **网络信息** 中查看。

### 按键手势（IO0）

| 手势 | 动作 |
| --- | --- |
| 单击 | 拍照（遵守自拍倒计时设置） |
| 双击（400 ms 内） | 数字变焦 1× ↔ 2× 切换，并写入 NVS |
| 长按（> 600 ms） | 从预览进入菜单 / 从菜单退出 |

### 摇杆

| 操作 | 预览 / 菜单中的效果 |
| --- | --- |
| 上 / 下 | 移动选中项 |
| 左 / 右 | 调整当前行的数值；图库中切换照片 |
| 短按 | 进入子菜单；子菜单内返回主菜单 |
| 按住 ≥ 1 s（仅图库） | 删除当前照片及其缩略图 |

### 菜单结构

| 菜单项 | 可调内容 |
| --- | --- |
| 相机设置 | 亮度 −2…+2、对比度 −2…+2、饱和度 −2…+2、白平衡 0–4 |
| 分辨率 | UXGA 1600×1200、SXGA 1280×1024、XGA 1024×768、SVGA 800×600、QVGA 320×240 |
| 照片质量 | Ultra Q5、High Q8、Medium Q10、Low Q15、Very Low Q20 |
| 图库 | 浏览照片；长按删除 |
| 变焦防抖 | 变焦 1×–4×、场景 标准/夜间/逆光、防抖 开/关 |
| 曝光设置 | 自动/手动、快门 0–1200、增益 0–30、倒计时、水印 |
| 网络信息 | IP、信号强度、推流状态、网页录制说明 |
| 返回 | 回到预览 |

设置修改后立即写入 NVS；关闭菜单、重新初始化相机时统一应用。

### 拍照流程

1. 可选自拍倒计时（标题栏逐秒显示，预览继续刷新）。
2. 相机切换到 JPEG 拍照模式，并重放保存的传感器设置。
3. 可选防抖连拍：拍 3 帧，保留 JPEG 码流最大的一帧。
4. 可选后处理：数字变焦裁剪和/或时间水印，共用一次解码-重编码。
   变焦 1× 且无水印时直接保存原始 JPEG，不做重编码。
5. 保存到 `/photo_*.jpg`，同时生成 128×96 缩略图到 `/thumb/`。
6. 若开启自动上传，则上传照片。
7. 返回预览模式并重新应用全部设置。

有 NTP 时间时文件名为 `photo_YYYYMMDD_HHMMSS.jpg`，否则为 `photo_<计数>.jpg`。

### LED 状态（板载 WS2812，GPIO48）

| 状态 | 表现 |
| --- | --- |
| 待机且 WiFi 已连接 | 暗绿呼吸 |
| 拍照成功 | 短促白闪（只在曝光结束后，不会影响成像） |
| AP 配网模式 | 蓝色慢闪，亮 0.5 s / 灭 0.5 s |
| 未连接 WiFi | 橙色慢闪，亮 0.5 s / 灭 0.5 s |
| 错误（如相机初始化失败） | 红色快闪 3 秒 |

## 网页控制台

在 Station 模式下访问 `http://<设备IP>` 或 `http://esp32s3cam.local`。

| 按钮 / 页面 | 路由 | 说明 |
| --- | --- | --- |
| 实时画面 | `/stream` | MJPEG 实时推流 |
| 远程拍照 | `POST /capture` | 设备端拍照（遵守倒计时设置） |
| 设备录像 | `POST /record?action=start\|stop` | 录像并以 AVI 存入 SD 卡 |
| 图库 | `/list` | 照片卡片：预览、下载、删除、上传 |
| 设置 | `/config` | 全部相机与功能设置 |
| 状态 | `/status` | 运行指标与录像文件列表 |
| 固件升级 | `/update` | 浏览器上传固件 |

### 实时推流与浏览器录像

- 点击 **实时画面** 打开 MJPEG 推流。
- 推流时点击 **录像**，浏览器用 `MediaRecorder` 把画面录成 **WebM** 保存到电脑；
  录制期间页面必须保持打开。
- 推流使用 SVGA JPEG、质量 12，在帧率与带宽之间取平衡。
- 推流时相机专门用于推流，TFT 本地预览会暂停。

### 机内录像（AVI）

- 点击 **设备录像**（或 `POST /record?action=start`）开始：相机切换到 240×240 JPEG，
  帧数据封装为 `/video_*.avi` 写入 SD 卡。
- 帧率由 `videoFps` 决定（5 / 10 / 15）。单段时长受索引表限制（约 10 分钟），
  剩余空间低于 2 MB 时自动停止。
- 录像与推流、拍照互斥。
- 再次点击停止；关闭文件前会回填 AVI 索引以及 RIFF/avih/strh/movi/idx1 各长度字段。
- 录像文件在 `/status` 页面列出并提供下载链接。

### 设置页

| 分组 | 设置项 |
| --- | --- |
| 图像 | 亮度、对比度、饱和度、白平衡、拍照分辨率、JPEG 质量、水平镜像/垂直翻转 |
| 镜头 | 数字变焦 1×–4×、场景预设、手持防抖、自拍倒计时、时间水印 |
| 曝光 | 自动/手动、快门 0–1200、增益 0–30 |
| 高级 | JPEG 预览、硬件窗口变焦、上传地址、自动上传、录像帧率 |

部分设置（预览模式、硬件变焦）在下次进入预览时生效，页面会给出提示。

### 照片上传

- 填写 **照片上传地址**，可勾选 **拍照后自动上传**。
- 请求为 `multipart/form-data`，字段名固定为 **`photo`**，因此任何接受照片字段的
  服务端都可使用。
- Telegram 示例：

  ```
  https://api.telegram.org/bot<BOT_TOKEN>/sendPhoto?chat_id=<CHAT_ID>
  ```

  HTTPS 地址会自动使用 TLS（设备端跳过证书链校验）。
- 上传超时 10 秒且不重试，失败不会阻塞拍照流程。图库卡片上也有手动 **上传** 按钮。

### 固件升级

两种方式：

1. **网页**：`/update` → 选择编译出的 `.bin` → 上传。镜像流式写入备用 app 分区，
   完成后设备自动重启。
2. **ArduinoOTA**：同一网络下，IDE 的网络端口列表会出现 `esp32s3cam`。

两者都要求分区方案包含 **两个 app 分区**。

### 调参建议

- **发热大 / 电池供电**：把 `PREVIEW_INTERVAL_MS` 调大（如 100–150 ms）降低帧率与功耗；
  需要极限省电可关闭 JPEG 预览。
- **想要更流畅的预览**：把 `PREVIEW_INTERVAL_MS` 调小（如 50 ms），或开启 JPEG 预览。
- **画面偏暗**：先试场景"夜间"，再用手动曝光（增大快门值、适度增益），或提高亮度。
- **运动糊片**：减小快门值（缩短曝光）并开启防抖。
- **TFT 花屏/白屏**：保持 `TFT_SPI_FREQ_HZ` 为 20 MHz，缩短 SPI 排线。

## 设计说明

### 任务分配

| 核心 | 任务 | 职责 |
| --- | --- | --- |
| Core 1 | `cameraTask` | 取帧、渲染预览（变焦 + 字节序转换）、喂看门狗 |
| Core 0 | Arduino `loop` | 菜单、摇杆/按键手势、WiFi、网页、OTA、LED、录像节拍 |

### 预览路径

- **RGB565（默认）**：传感器把 RGB565 写入 PSRAM，预览任务做字节序转换并绘制 128×96 到 TFT。
- **JPEG（可选）**：传感器输出 128×128 JPEG，TJpgDec 只解码可见的 128×96 窗口
  （或变焦裁剪窗口）到 PSRAM 缓冲，再绘制上屏。每帧 PSRAM 流量从 32 KB 降到几 KB，
  发热更低，也给更高帧率留出余量。

### 拍照变焦

- **软件（默认）**：TJpgDec 只解码裁剪窗口，RGB888 结果用 `fmt2jpg` 重编码。
  即使 UXGA 也保持内存可控。
- **硬件（可选）**：用 OV2640 `set_res_raw()` 窗口裁剪，拍照与 MJPEG 推流都零 CPU、
  无需重编码。仅支持 4:3 预设（UXGA / SVGA / QVGA），其它尺寸自动回退软件裁剪。

### 水印与缩略图

变焦与水印共用一次解码-重编码。缩略图按 1/8 比例解码以节省内存，在主图安全保存后
才生成；缩略图失败不会导致照片丢失。

### 可靠性

- 连续 3 次取帧失败会触发相机 deinit/init，并有 10 秒节流。
- SD 写入失败会重挂载一次并重试一次。
- 预览、拍照、录像任务在长耗时操作前后喂看门狗。
- 每次切换相机模式都会重放传感器设置，因为 `esp_camera_init()` 会重置传感器。

## 故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 屏幕一直白屏 | TFT SPI 太快、排线松、背光未点亮 | 保持 `TFT_SPI_FREQ_HZ` 20 MHz；检查 CS/DC/RST/MOSI/SCLK；确认 BL 为高 |
| 串口打印 `Camera FAIL` | PSRAM 未选 OPI、摄像头排线松、供电弱 | 设置 PSRAM = OPI PSRAM；重插摄像头排线；使用 5 V/1 A 电源 |
| 屏幕提示 `SD Err!` | 卡不是 FAT32、接线问题、卡太慢 | 格式化为 FAT32；检查 CLK 39 / CMD 38 / D0 40；重插卡 |
| 找不到 `ESP32-S3-CAM-Setup` 热点 | 板子未启动，或已连上路由器 | 查看串口日志；5 GHz 网络不支持 |
| 网页打不开 | 不在同一网段，或系统不支持 mDNS | 用串口打印的 IP；让手机与相机连同一路由器 |
| 设置像是不生效 | 未保存，或预览模式需重新进入预览 | 点击 **保存**；修改预览/硬件变焦后重新进入预览 |
| 上传失败 | 地址不可达、Token 错、服务端不认字段 | 用浏览器/curl 测试地址；字段名必须是 `photo`；查看串口日志 |
| OTA 失败 | 分区方案没有 OTA 分区，或固件太大 | 使用 `16M Flash (3MB APP/9.9MB FATFS)`；app 需小于 3 MB |
| 录像提前停止 | SD 空间不足（< 2 MB）或索引到达上限 | 清理空间；重新开始一段录像 |
| AVI 无法播放 | 断电导致文件未收尾 | 关机前先停止录像；用 VLC 播放 |
| 变焦出现绿/紫边 | 硬件变焦窗口未对齐 | 关闭 `hwZoom`，软件变焦无此问题 |
| 照片太暗 | 光线不足 / 快门太短 / 亮度低 | 试"夜间"场景，提高亮度或快门值，开启防抖 |
| 水印时间错误或没有 | 无法 NTP 对时（无外网） | 连接有外网的路由器；时间无效时会跳过滤水印 |
| 拍照时设备重启 | 摄像头/SD 电流尖峰导致掉电 | 换更强的 5 V 电源，缩短电源线 |

### 出问题时的第一步

1. 打开串口监视器（**115200**），看启动横幅。
2. 确认 PSRAM 显示 **8.0 MB**。
3. 若要使用 OTA，确认分区方案包含两个 app 分区。
4. 确认所有外设共地且使用 3.3 V 逻辑。

## 常见问题与限制

**推流时 TFT 预览还在刷新吗？**
不会。推流会把相机切到 SVGA JPEG 并暂停预览任务，TFT 停留在最后一帧直到推流结束。

**可以同时推流和机内录像吗？**
不可以。推流、机内录像、拍照互斥，因为它们需要相机处于不同模式。

**数字变焦对 MJPEG 推流有效吗？**
只有开启 `hwZoom` 时有效。软件变焦只作用于预览与拍照，推流保持原始视角。

**可以几个客户端同时看推流？**
只能一个。网页服务是单线程的，第二个客户端会等待或失败。

**最高拍照分辨率是多少？**
OV2640 的 UXGA 1600×1200（200 万像素）。

**为什么搜不到 5 GHz WiFi？**
ESP32-S3 只支持 2.4 GHz。

**必须联网才能用吗？**
只有 NTP 对时、照片上传和网页 OTA 需要外网；局域网推流与拍照不需要。

**可以用电池供电吗？**
可以，但要保证稳定的 5 V。主要风险是摄像头与 SD 的电流尖峰，建议在板子附近加储能电容。
